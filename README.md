# Nestora Home Appliances

Responsive client demo with floating category navigation, product search, demo shopping bag, and WhatsApp enquiries.

## Preview
Open index.html through a static HTTP server. The site uses relative asset paths and hash routes, so it works under a GitHub Pages project URL.

## Deployment
GitHub Pages: main branch, / (root).

## Demo content
Prices were transcribed from the supplied promotional material and require confirmation. AI-assisted product cutouts and hero appliances are illustrative. Gardening products are not listed yet. No payments or orders are processed.
